# Isuru Anjana — Portfolio

Personal portfolio of Isuru Anjana, Electrical Engineering undergraduate at the University of Moratuwa.

Live site: https://isuruanjanagalle.github.io/portfolio/

A static site (HTML, CSS, vanilla JS): a scroll-driven background video built from 200 WebP frames, electric circuit effects, and sections for education, projects, LinkedIn posts and skills.

To preview locally, from the folder above this one:

```bash
python serve.py
```
